Spinchy KPI Dashboard

Fullstack KPI-dashboard bygget til en reel virksomhed. Aggregerer ordredata fra tre systemer — Rackbeat lager-API, C1st POS og webshop — og præsenterer omsætning, dækningsbidrag og topsælgere med år-til-år sammenligning på tværs af salgskanaler. Fullstack KPI dashboard built for a real company. Aggregates order data from three systems — the Rackbeat inventory API, C1st POS and webshop — presenting revenue, contribution margin and top sellers with year-over-year comparison across sales channels.

Hvad løser detWhat it solves

  • → Samler ordredata fra tre adskilte systemer i én database, så ledelsen slipper for at hente tal manuelt fra tre stederConsolidates order data from three separate systems into one database, so management no longer needs to pull numbers manually from three places
  • → Viser omsætning, dækningsbidrag og index med sammenligning mod samme periode sidste årShows revenue, contribution margin and index with comparison to the same period last year
  • → Topsælger-tabel med sortering på omsætning, DB og DG%Top-seller table sortable by revenue, contribution margin and margin %
  • → Kanalfilter — kan isolere data pr. butik eller webshopChannel filter — can isolate data per store or webshop
  • → JWT-login så dashboardet er beskyttetJWT login so the dashboard is protected

ArkitekturArchitecture

Frontend

Vanilla JavaScript med komponent-arkitektur — KpiRow, MarginCard, TopProductsTable, ChannelPicker, DatePickerVanilla JavaScript with a component architecture — KpiRow, MarginCard, TopProductsTable, ChannelPicker, DatePicker

Backend

Java Spring Boot REST API med JWT-autentifikation. Henter og normaliserer data fra Rackbeat og C1st API'erne og gemmer i MySQLJava Spring Boot REST API with JWT authentication. Fetches and normalizes data from the Rackbeat and C1st APIs and stores it in MySQL
